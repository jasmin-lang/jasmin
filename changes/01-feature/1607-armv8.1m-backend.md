- Add an ARMv8.1-M backend: new target architecture `-arch armv8.1m`, for
  the processors that implement ARMv8.1-M with the Main and DSP extensions
  (e.g., Cortex-M55). It shares its instructions, its compilation passes and
  their correctness proofs with the `arm-m4` backend: the ARM architecture is
  parameterized by its version. It adds the conditional selects `CSEL`,
  `CSINC`, `CSINV` and `CSNEG`, compiles conditional assignments between
  registers to `CSEL`, and classifies the instructions that have data
  independent timing (`jasmin-ct --doit`) as the Armv8-M Architecture
  Reference Manual does
  ([PR #1607](https://github.com/jasmin-lang/jasmin/pull/1607)).
