- Add an ARMv8.1-M backend: new target architecture `-arch armv8.1m`, also
  named `cortex-m55` and `cortex-m85`, for the processors that implement
  ARMv8.1-M with the Main and DSP extensions. It shares its instructions, its
  compilation passes and their correctness proofs with the `cortex-m3` and
  `cortex-m4` targets, whose core carries the version of the architecture.
  It adds the conditional selects `CSEL`, `CSINC`, `CSINV` and `CSNEG`,
  compiles conditional assignments between registers to `CSEL`, and
  classifies the instructions that have data independent timing
  (`jasmin-ct --doit`) as the Armv8-M Architecture Reference Manual does
  ([PR #1676](https://github.com/jasmin-lang/jasmin/pull/1676)).
